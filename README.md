## Python / Pygame

Install the basic Python dependencies:

```bash
python3 -m pip install pygame numpy
```

Run the Canon witness:

```bash
cd Physics_Py
python3 canon_emergent.py
```

Or run one of the selected variations:

```bash
python3 emergent_void_physics8.py
```

A render window should open. Close the window to stop the field.

Some scripts may behave differently depending on local performance, fonts, display settings, and Pygame support.

That is expected.

## Raylib / C

The Raylib engines require a C compiler, Raylib, OpenGL support, and the shader files included in each engine folder.

On Linux, the general path may look like:

```bash
sudo apt install build-essential libraylib-dev
cd Physics_Ray/The_Quantum_Jitter
make
./alqc_gpu
```

On macOS or Windows, build using your local Raylib toolchain.

The included `Makefile` files are starting points, not universal commandments. Adjust include paths, library paths, and linker flags as your system requires.

The source is provided so the witness can be rebuilt.

The binary is only a body. The source is the anatomy.

---

## Runtime Assets

Do not move the executables away from their folders unless you also move their required assets.

The Raylib engines may depend on nearby files such as:

```text
shaders/*.comp
shaders/*.vert
shaders/*.frag
whisper.txt
poem.txt
```

The `.c` source is not required to run a compiled binary, but the shaders and local runtime assets may be required.

If the binary fails, compile locally.

If the render fails, check drivers, Raylib, OpenGL, paths, and permissions.

If the glyphs become boxes, check fonts.

---

## Glyphs and Font Failure

Some engines use symbolic glyphs.

Depending on your operating system, font stack, terminal, windowing environment, and render path, some glyphs may appear as empty boxes or replacement characters.

This does not necessarily mean the physics failed.

It may mean the alphabet failed.

A field may still be running beneath a broken witness-font.
